🏗️ AI-Based Industrial Safety Monitoring (PPE Detection)
تم تطويره بواسطة المهندس سليمان كديمي
نظام ذكاء اصطناعي يعتمد على الرؤية الحاسوبية (Computer Vision) لمراقبة الالتزام بمعدات الوقاية الشخصية في المواقع النفطية والإنشائية.

🚀 المميزات
اكتشاف فوري (Real-time): رصد العمال والمعدات عبر الكاميرا المباشرة.

تعدد الفئات: تم تدريب الموديل على 10 فئات تشمل (الخوذة، السترة، الأقماع، البشر، والآليات).

كفاءة الموارد: تم تحسين الموديل ليعمل بدقة عالية على أجهزة الحاسوب العادية (CPU).
